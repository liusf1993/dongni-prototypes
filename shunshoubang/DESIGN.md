# 移动端账单原型

用户明确要求仅移动端、以晒账单为核心。最大宽度 430px，白暖灰背景，固定底部「逛账单 / 收藏 / 晒账单 / 帮付 / 我的」导航；不包含桌面侧栏或宣传说明区。

主体为用户晒的凭证：人物、账单名称、简短附言、账单凭证、剩余金额、查看入口。示例凭证采用淡绿电子账单布局，明确标识「示例凭证」，上传凭证原样以图片预览。

背景 #faf9f6，文字 #292d30，辅助 #6b726a，主操作 #c85e36，账单底 #f2f5ef。系统中文字体，标题 23–25px，正文 12–13px，金额 28–30px。SVG 统一线性图标。卡片15px圆角，票据9px，按钮8px。支持减少动效、焦点样式、错误与空状态。

晒账单使用独立全屏表单；帮付与详情使用手机弹层。左右滑动对应跳过与打开帮付确认，不直接扣款。截图选择支持 JPG/PNG/WebP，最大5MB，压缩最长边1000px，发布后本机保存。
