# 顺手帮移动端原型

## 结果

新增「晒账单」移动端原型，仓库首页新增入口，保留已有智能批改审核原型。

## 功能

- 手机宽度单列账单凭证，分类、左右滑动、撤回、收藏和账单详情。
- 晒账单要求上传截图，支持格式与5MB大小校验、压缩、预览和重新选择；填写名称、金额、分类，附言选填。
- 模拟全额或部分帮付、剩余金额更新及个人记录；上传截图和操作记录仅保存在浏览器。
- 提供移动端首页和发布页截图、产品与设计说明。
