# 顺手帮 · 晒账单移动端原型

[在线体验](https://liusf1993.github.io/dongni-prototypes/shunshoubang/)

用户晒出待支付账单的截图和金额，浏览者左右滑动选择跳过或帮付。仅移动端界面，电脑打开同样显示手机宽度。

支持截图上传与预览、晒账单、分类、滑动与撤回、收藏、全额或部分模拟帮付，以及个人记录。发布内容、截图和操作记录保存在当前浏览器，不会上传到 GitHub。

账单示例用于体验；帮付为模拟，不产生真实扣款。

本地启动：在此目录运行 `python3 -m http.server 5173 --bind 127.0.0.1`，访问 http://127.0.0.1:5173 。无构建依赖。

验证：系统 Google Chrome 验证截图上传、发布与刷新恢复、收藏、撤回、部分帮付和金额更新；390×844 和 320×740 手机布局检查通过。
