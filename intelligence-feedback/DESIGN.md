# 智能批改原型视觉与交互

## Surface
模式：Operate。既有页面扩展，继承青绿品牌和阅卷操作习惯，直接以代码制作。

## Visual System
青绿主操作色 #007e82，浅灰画布 #f3f6f7，白色内容面。
中文系统字体配合模拟作答的楷体。不以身份信息辅助评分。
边框表达工作区层级，浮动工具和比较弹窗使用柔和投影。
图标为统一描边 SVG；原型控制条与产品界面区分。

## Variants
- A 边审边教：分数组与作答网格，右侧嵌入标准共创，适合连续阅卷。
- B 案例共创：按分歧导航，横向比较正例、反例与部分给分例，适合集中澄清。
- C 分步校准：确认标准、样卷校准、审核作答、反馈回看，适合首次使用。

## Interaction Contract
逐份改分仅改变当前答卷。选择原因不会自动生效为评分规则。
样卷评分必填；规则为空、分数越界均有提示。
预览计算候选副本，只有确认时才更新勾选答卷。
样卷判断与预设规则冲突时暂停应用，避免虚假模拟任意规则理解。
原生 dialog 限定焦点；正文单独滚动，底部动作不覆盖内容。
布局切换保留共享状态，输入时不抢占方向键。
手机重排工作区与样例列，浮动切换条预留底部空间。
