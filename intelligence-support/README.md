# 智能批改：短期问题反馈闭环

目标是让老师以最少输入报告具体问题，并能跟踪处理结果。ABC 保留为长期探索，本页面不要求老师校准样卷或抽象评分规则。

## 设计取舍
- 主页面保留阅卷结构，仅增加学校规则摘要、作答反馈按钮、我的反馈及交流群入口。
- 反馈自动关联当前题目、作答、提交时分数及规则快照。标签和说明均可跳过，收到反馈后评分保持不变。
- 同一作答已有反馈则进入已有记录。已收到、处理中、待您验证、已解决分开；仍有问题可在原记录补充。
- 学校规则使用可理解的业务配置，不向老师暴露提示词或后置处理代码。普通老师只读，学校负责人配置。
- 学校＋科目是本次核对的 intellijmarkserv 既有能力。年级、题型、考试、题目范围是新增设想，不表示后端已经支持。
- 建议当前试用默认本次考试；更广的学校长期范围由负责人管理，变更留记录。原型保存后不重评已有分数。
- 未提供真实入群二维码，因此明确显示待配置占位，不生成假群码。页面反馈不要求入群；有编号可复制到群沟通。

## 运行与演示
在仓库根目录执行 python3 -m http.server 6427 --bind 127.0.0.1，打开 /intelligence-support/。
全部材料虚构，无后端请求，刷新清空；身份和团队进展均为演示控制，不是实际权限与客服能力。
真实实施还需对接学校权限、范围冲突优先级、反馈工单和通知机制、真实群二维码。反馈附件应按当前账号权限取最小必要上下文，不上送整班数据。
