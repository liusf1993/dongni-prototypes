# 智能批改反馈共创原型

<!-- impeccable:product-schema 1 -->

## Platform
web

## Users
主要使用者是审核智能批改结果的老师，教研组负责人负责共同评分标准的澄清。

## Product Purpose
探索老师与系统共同建立、检验和维护评分标准的方式，使单次纠正能够帮助后续批改。
用户确认本次要走通反馈闭环，并比较不同布局。

## Operating Context
基于既有智能批改页面的题号、分数组、作答审核与给分标准结构。
这是独立、可丢弃的静态原型，发布至公开 GitHub Pages；用户已明确选择公开发布。

## Capabilities and Constraints
三种布局共享内存状态，通过 URL 参数切换。展示样卷校准、逐份核对、
原因补充、规则影响预览、选择复查范围、评分档案和反馈记录。
全部材料和答卷独立编写且为虚构数据。不会调用业务接口。
刷新恢复初始状态。模型理解、规则匹配和新样本验证使用预设模拟。
业务仓库不做修改；没有选定正式产品方案或实施范围。

## Brand Commitments
沿用懂你智能批改页面的青绿色、白色工作区和熟悉的阅卷结构。

## Product Principles
- 明确评分依据及适用范围，个人操作偏好与共同评分标准分开。
- 反馈记录不等于规则生效，预览不等于评分改变。
- 同时使用有效例与边界例澄清标准。
- 实际复查由老师明确选择，处理进度不宣称为准确率。

## Evidence on Hand
当前 fat-web 页面结构的只读调查和既有 intelligence-review 公开原型的视觉截图。
用户确认：不启用分阶段开发流程；完整反馈闭环；比较布局；公开 GitHub Pages。
